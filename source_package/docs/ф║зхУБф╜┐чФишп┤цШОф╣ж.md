# 成本测算与合同归档管理平台 · 产品使用说明书

> 版本：v1.0 · 更新日期：2026-08-17

---

## 一、产品概述

本平台是面向汽车制造成本工程师与管理员的一站式工具，覆盖**成本模型建模 → Excel 批量测算 → 历史合同归档 → 价格快速查询 → AI 智能核算**全流程。

**核心价值**

- 上传 Excel 自动匹配模型并完成批量费用测算
- 建立可复用的公式模型，支持试算验证与版本发布
- 合同数据归档入库，支持审核流程与批次管理
- 历史价格多维检索，辅助采购决策
- AI 对话式助手，上传文件即可智能核算

---

## 二、模块导航

平台共 6 个功能模块，通过左侧深色侧边栏切换：

| 菜单名称 | 路由 | 核心用途 |
|---------|------|---------|

## 三、测算工作台

### 3.1 功能说明

上传 Excel 设备清单，系统自动匹配适用模型并完成批量费用测算，输出测算结果与异常检测报告。

### 3.2 操作步骤

1. **上传文件**：点击上传区域或将 Excel 文件拖拽至上传区，系统自动开始解析
2. **查看进度**：上传后页面顶部显示测算进度条，实时展示处理行数
3. **查看统计**：测算完成后，顶部统计卡片展示总数 / 通过 / 异常 / 缺失等汇总数据
4. **筛选明细**：在结果表格上方按「全部 / 通过 / 异常 / 缺失」标签筛选查看
5. **异常检测**：页面下方异常检测卡片列出价格偏差较大的记录，标注偏差等级
6. **下载结果**：点击下载区按钮，可下载完整结果或仅异常结果
7. **重置测算**：如需重新测算，点击重置按钮清空当前任务

### 3.3 注意事项

- Excel 需包含设备/材料名称等必要列，否则无法匹配模型
- 测算任务在页面刷新后可通过 sessionStorage 自动恢复
- 未匹配到模型的设备会标记为「缺失」，需前往批量参数填报补充

## 四、批量参数填报

### 4.1 功能说明

针对测算工作台中未自动匹配或需手动补充参数的设备，提供分组填报界面，支持批量套用模型并重新测算。

### 4.2 操作步骤

1. **进入填报**：系统自动加载最新测算任务的待填项，按分组展示
2. **查看分组**：左侧分组列表按设备类型分组，点击切换查看不同组
3. **填写参数**：在右侧表格中为每个设备填写模型所需的输入参数
4. **批量套用**：填写完成后点击「批量套用」按钮，系统按模型公式计算价格
5. **套用模型**：可手动为指定设备选择模型并套用
6. **提交结果**：确认无误后点击提交，将测算结果写回任务

### 4.3 注意事项

- 参数需符合模型定义的类型（数值/文本），必填项不能为空
- 批量套用仅对参数齐全的设备生效，缺失项仍保留待填状态

## 五、历史合同归档

### 5.1 功能说明

将历史合同 Excel 数据归档入库，支持自动解析、预览校验、审核流程、批次管理与数据检索。

### 5.2 上传归档

1. **下载模板**（可选）：点击「下载模板」获取标准 Excel 模板
2. **上传文件**：将填好的 Excel 拖拽至上传区，系统自动解析
3. **自动识别**：系统自动识别文件名中的线别信息并预填
4. **预览校验**：解析完成后展示预览表格，数据分为「有效」和「无效」两类
5. **提交归档**：确认数据无误后点击提交，进入审核流程

### 5.3 审核流程（管理员）

- 提交后的归档批次状态为「审核中」
- 管理员在审核面板查看待审核批次及明细
- 可执行「通过」或「驳回」操作，驳回时需填写原因
- 审核通过后数据正式入库，可在已归档数据中检索

### 5.4 已归档数据管理

- **Tab 切换**：支持「近期归档」「远期归档」「批次管理」三个视图
- **项目筛选**：在近期/远期归档视图，可通过搜索框按项目名称筛选
- **分页浏览**：支持翻页和跳转到指定页码
- **批量删除**：勾选记录后可批量删除
- **批次管理**：
  - 以固定高度窗口滚动查看所有归档批次
  - 支持按批次名称搜索筛选
  - 可删除整个批次（含确认弹窗，操作不可恢复）
- **作废重提**：已归档数据如需修改，可作废后重新提交

### 5.5 注意事项

- 上传文件格式须为 .xlsx 或 .xls
- 无效数据行会在预览时标红，可修正后重新上传
- 已审核通过的数据不可直接修改，需通过作废流程处理

## 六、历史价格快查

### 6.1 功能说明

从已归档合同数据中，按设备名称、线别、使用范围、供货方式等多维度快速检索历史价格。

### 6.2 操作步骤

1. **输入条件**：在搜索栏输入设备/材料名称关键词
2. **多维筛选**：可选择线别、使用范围、供货方式进行过滤
3. **查看结果**：结果列表展示单价、价格口径、品牌、工位、归档日期等字段
4. **导出数据**：点击导出按钮，可将查询结果导出为 Excel（最多 10000 条）

### 6.3 注意事项

- 搜索数据来源为已审核通过的归档合同
- 价格口径默认为「未税」，请注意区分

## 七、建模台

### 7.1 功能说明

创建和管理成本测算模型，定义输入参数、计算公式和常量，支持试算验证与版本发布。

### 7.2 模型列表

- **新建模型**：点击左上角「新建」按钮创建空白模型
- **选择模型**：点击列表项加载模型到编辑器
- **删除模型**：点击模型名称右侧的删除图标，确认后删除（不可恢复）
- **状态标识**：模型分为「草稿」和「已发布」两种状态

### 7.3 模型编辑

1. **基本信息**：填写模型名称和适用类型（如焊接夹具、改造设备等）
2. **输入变量**：添加模型所需的输入参数，每个变量包含：
   - 名称：变量名（在公式中以 `@变量名` 引用）
   - 类型：数值 / 文本
   - 是否必填
   - 描述说明
3. **常量定义**：添加公式中使用的固定常量（如钢材单价、人工费率等）
4. **公式逻辑**：编写计算公式，支持四则运算、max/min 等函数
   - 变量引用：`@变量名`
   - 常量引用：直接使用常量名
   - 示例：`@光电开关*2500 + @接近开关*550 + @气缸数量*气缸均价`
5. **保存模型**：点击保存按钮，模型保存为草稿状态

### 7.4 试算与发布

1. **试算验证**：在右侧试算面板输入测试参数值，点击试算
2. **查看结果**：系统执行公式计算，显示试算结果和通过/失败状态
3. **发布模型**：试算通过后点击「发布」按钮，模型状态变更为「已发布」
4. **版本管理**：发布后会生成版本号，可在版本历史中查看

### 7.5 注意事项

- 公式中引用的变量名需与输入变量定义一致
- 常量值修改后需重新保存模型
- 已发布的模型可被测算工作台自动匹配使用
- 删除模型不可恢复，请谨慎操作

## 八、AI 核算助手

### 8.1 功能说明

通过对话方式与 AI 助手交互，上传 Excel 文件即可自动完成设备匹配、模型套用和费用测算。

### 8.2 操作步骤

1. **新建会话**：点击左侧「新建会话」开始对话
2. **上传文件**：在对话框中上传 Excel 设备清单
3. **智能处理**：AI 自动解析文件、匹配模型、执行测算
4. **查看进度**：对话中实时展示处理状态（匹配中 / 套用中 / 测算中）
5. **动作确认**：AI 可能提出需要确认的操作，可选择「确认」或「驳回」
6. **查看结果**：测算完成后可直接跳转测算工作台查看详细结果
7. **会话管理**：左侧会话列表可切换历史会话或删除会话

### 8.3 注意事项

- 每次会话独立，切换会话不会丢失历史记录
- 文件上传后 AI 需要一定处理时间，请耐心等待
- 驳回操作需说明原因，AI 将根据反馈调整方案

## 九、角色与权限

系统内置三种角色，由管理员在平台角色面板中分配。

| 角色 | 标识 | 权限范围 |
|------|------|---------|

## 十、常见问题

### Q1：上传 Excel 后提示「无法匹配模型」？

确认建模台中是否存在与设备类型匹配的已发布模型。模型需处于「已发布」状态才会被自动匹配。

### Q2：测算结果中有「异常」标记是什么意思？

表示该设备的测算价格与历史均价偏差较大。可查看异常检测卡片中的偏差等级和具体数值，核实输入参数是否正确。

### Q3：合同归档提交后可以修改吗？

审核中的批次如需修改，可由管理员驳回后重新上传。已审核通过的数据需通过作废流程处理。

### Q4：模型公式支持哪些函数？

支持基础四则运算（+、-、*、/）以及 `max`、`min` 等常用数学函数。变量用 `@变量名` 引用，常量直接使用名称。

### Q5：AI 核算助手支持哪些文件格式？

目前支持 .xlsx 和 .xls 格式的 Excel 文件，文件需包含设备/材料名称等必要信息。

### Q6：历史价格快查导出有数量限制吗？

单次导出最多 10000 条记录。如需导出更多数据，请缩小筛选范围分批导出。
