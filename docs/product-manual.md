# 焊装费用智能测算与管理系统 · 产品使用说明书

> 版本 1.0 · 2026-09

## 一、产品简介

本系统面向汽车焊装工艺成本核算场景，提供从**预算清单导入、智能模型匹配、参数测算**，到**历史合同归档、价格快查、模型维护**的一体化能力，并内置 AI 核算助手辅助完成测算任务。

核心工作流：

```
预算清单上传 ──► 智能匹配与测算 ──► 待填项批量填报 ──► 成果导出
历史合同归档 ──► 审核入库 ──► 价格快查 / 测算寻价参考
```

## 二、页面导航与权限

系统左侧为导航栏，共 7 个功能页面。不同角色可见的页面由管理员在「角色管理」中配置权限点位决定：

| 页面 | 路径 | 所需权限 | 用途 |
|------|------|----------|------|
| 测算工作台 | `/` | 测算任务-创建 | 上传预算清单并完成智能测算 |
| 批量参数填报 | `/batch-fill` | 待填项-更新 | 补全测算所需参数并提交合并 |
| 历史合同归档 | `/contract-archive` | 合同归档-查看 | 上传、审核历史合同数据 |
| 历史价格快查 | `/price-query` | 价格查询-查看 | 按条件检索历史合同价格 |
| 建模台 | `/model-studio` | 模型-查看 | 维护核算模型、公式与常量 |
| AI 核算助手 | `/agent` | AI 助手-使用 | 对话式发起与跟踪测算任务 |
| 角色管理 | `/role-management` | 权限-管理 | 配置角色、成员与权限点位 |

若某页面提示无权访问，请联系系统管理员调整角色权限。

## 三、测算工作台（首页）

### 3.1 上传与测算

1. **选择核算对象**：焊装库 / 制造费用库。
2. **选择产线**（仅焊装库）：侧围 / 开闭件 / 下车体 / 主线。
3. **选择测算模式**：
   - 目标价模式（标准测算）；
   - 预算模式（按预算清单字段测算）；
   - 指定项目匹配（按选定历史项目合同价格匹配）。
4. **上传清单文件**：支持 xlsx / xls / pdf / docx / doc / png / jpg，单文件上传。图片与文档会自动做文字识别后解析。

### 3.2 Excel 模板列名

系统按表头名称识别列，请使用以下列名：

> 序号、工位号、工位描述、设备材料名称、类别、区分、供货、复制镜像、规格备注、数量、单位、单价未税、总价未税、备注

其中「规格/备注」或「规格」列的内容会带入测算明细与批量填报页的「规格/备注」列。

### 3.3 结果解读

- 上传后自动进入测算，页面顶部显示进度条与 4 张统计卡：**共计 / 成功 / 甲供不计费 / 待人工**。
- **甲供不计费**：供货方式为甲供的行，按 0 元计费，视为成功。
- **待人工**：需要人工补充参数的行，点击统计卡可跳转到「批量参数填报」页处理。
- **异常检测卡片**：测算完成后展示风险等级、异常设备清单与整体评估建议。
- 主成果表支持分页浏览与筛选；右上角可导出「无损回填」Excel。

### 3.4 明细状态说明

| 状态 | 含义 |
|------|------|
| success | 已成功测算 |
| jia_gong | 甲供不计费（计 0） |
| pending | 待人工补参 |

## 四、批量参数填报

处理测算工作台跳转过来的「待人工」行。

1. 左侧分组侧栏包含三类：
   - **模型参数**：已匹配核算模型，需补模型输入参数；
   - **改造白盒**：改造类设备，按白盒方式填报；
   - **无据待处理**：暂无匹配模型或历史依据的行。
2. 表格中可勾选多行，批量选择模型应用。
3. 点击行内魔棒按钮触发 **AI 参数提取**：系统依据规格备注自动推荐参数值，可采纳或修改。
4. 「规格/备注」列默认单行收起，点击「展开」查看完整内容。
5. 填写完成后点击底部 **提交合并**，结果回传测算工作台并刷新成果表。

## 五、历史合同归档

### 5.1 上传

1. 顶部选择合同库：**焊装合同库**（分线别）或 **制造费用合同库**（不分线别，含规格型号字段）。
2. 拖拽或点选上传，单次最多 **4 个文件**，支持 xlsx / xls / pdf。
3. Excel 自动从文件名识别线别（侧围 / 开闭件 / 下车体 / 主线），识别不到时默认主线；制造费用库不识别线别。
4. 焊装模板 15 列（含线别、类别、区分、复制镜像、供货、工位号等）；制造费用模板 10 列（含规格型号）。
5. PDF 文件采用分片方式自动上传，单个文件上限 30MB，无需人工干预。

### 5.2 预览与提交

解析完成后进入预览表，可删除不需要的行或文件，确认无误后**提交审核**。

### 5.3 审核

- 提交后记录状态为「待审核」，由具备审核权限的管理员在审核面板操作。
- 管理员可**通过**或**驳回**，并可填写备注说明。
- 审核通过后数据入库，供价格快查与测算寻价使用；页面下方可查看已归档数据与归档日志。

## 六、历史价格快查

只读查询页，用于快速获取历史合同价格参考。

1. 筛选条件：合同库、设备名称（模糊搜索）、线别、专通用（专用 / 通用）、供货方式（甲供 / 乙供 / 甲指乙供）。
2. 命中记录展示：项目、设备、线别、供货、单价、品牌、工位号、工位描述、归档日期。
3. 右侧**参考价卡片**展示均价、价格口径说明与跨线备注。
4. 支持导出 Excel，单次最多 1 万条。

## 七、建模台

维护测算模型，三栏布局：**模型列表 / 编辑器 / 试算验证**。

1. **模型列表**（左栏）：新建、删除模型；模型分「草稿」与「已发布」两种状态。
2. **编辑器**（中栏）：定义模型输入参数、常量、计算公式逻辑。
3. **试算验证**（右栏）：填写参数试运行，验证通过后方可**发布**模型；已发布模型进入版本审计。
4. **版本审计**：记录每次变更的操作人、时间与变更日志，可追溯。

## 八、AI 核算助手

对话式完成测算任务。

1. 左侧会话列表支持新建与删除会话。
2. 中间对话区可直接发送文字，或上传 Excel 清单。
3. AI 发起的工具动作（如创建测算任务）会以动作卡片形式出现，需您手动**确认**或**拒绝**后才会执行。
4. 任务执行期间系统自动轮询状态，完成后提示「前往测算工作台查看」，点击即可跳转结果页。

## 九、角色管理

仅权限管理员可见。

1. 角色列表展示名称、描述、角色标识、权限点位徽章与成员摘要。
2. 支持添加、编辑、删除角色（全员角色与公开角色不可删除）。
3. 可编辑角色成员、勾选配置 7 个权限点位（对应上表 7 个页面）。
4. 权限调整对成员实时生效。

## 十、常见问题

| 问题 | 处理方式 |
|------|----------|
| 上传 Excel 后「规格/备注」列为空 | 检查表头是否为「规格/备注」或「规格」，并确认该列有内容；旧任务需重新上传 |
| 行状态一直是「待人工」 | 前往「批量参数填报」页补全参数后提交合并 |
| 上传 PDF 报错 | 确认文件小于 30MB；若仍失败请稍后重试或改用 Excel |
| 页面提示无权限 | 联系管理员在「角色管理」中为您的角色增加对应权限点位 |
| 测算结果中甲供行价格为 0 | 属预期行为，甲供不计费 |
